# Security

[日本語](SECURITY.ja.md) | **English**

Do not post vulnerabilities, credentials, or customer information in ordinary Issues or PRs. Maintainer **mhimt** can be contacted privately at [sporks-framer9t@icloud.com](mailto:sporks-framer9t@icloud.com). Send only a summary with sensitive information removed at first. Receipt of a test email has been confirmed. Handling procedures remain unverified, and response times are not guaranteed. [GitHub private vulnerability reporting](https://github.com/mhimt-lab/illustrator-studio-mcp/security/advisories/new) is also enabled.

The scope is Public Beta 0.1.0-beta.4. There is no guarantee of a Stable release or a maintenance period. Include the version, checksum, OS, Illustrator and AI app versions, and reproduction steps using synthetic data.

This tool uses local file permissions and permission to control Illustrator. Overwrite save requires target verification and a backup. A backup does not guarantee restoration of the whole document, every appearance, or external links. External files are subject to their own permissions and rights. Do not repeat an operation with an unknown outcome under a new ID. Preserve the records and follow the [recovery steps](docs/runbook.en.md).
