# 使い方と依頼例

**日本語** | [English](usage.en.md)

修正の手数を減らして、デザインを詰める時間へ。

見出しを差し替える。写真を入れ替える。図形の位置を揃える。繰り返す制作作業を、いつもの言葉で AI に頼めます。制作の意図はあなたが決め、作業を AI と分担できます。

セットアップは [README のクイックスタート](../README.md#クイックスタート) を参照してください。

> **Public Beta 0.1.0-beta.2。** 試用版です。制作ファイルのコピーで試してください。Illustratorを前面に表示し、画面ロックを解除した状態で使います。対応範囲は [Betaの範囲](../README.md#betaの範囲) を確認してください。

## 最初は、データを変えずに試す

セットアップしたら、確認用のファイルを開いて、AI にこう頼んでみてください。

```text
Illustrator Studio MCPを使って、開いているドキュメントと
選択中のオブジェクトを教えて。まだ何も変更しないで。
```

読み取りツールは Illustrator のデータを変更しません。まずは AI が何を把握できるかを見てから、ひとつの修正へ進めます。

1. **対象を伝える。** 編集したい文字や図形を選択し、どこをどう変えたいか伝えます。
2. **計画を確かめる。** AI が示す対象と変更内容を確認します。
3. **適用を頼む。** 実行後の結果を確認し、Illustrator 上でも仕上がりを見ます。

編集前にはファイルを保存してください。計画後に手作業で編集した場合は、その状態で新しく計画を取り直します。

## こんな作業から任せられます

### 告知内容が変わったら、文字をまとめて差し替える

見出しやラベルの変更を、一つずつ探して打ち直す作業から。複数の一行テキストをまとめて置き換えたり、一部の言葉だけを直したりできます。

```text
選択した一行の見出しを「週末限定フェア」に差し替えて。文字サイズと色はそのままにして、まず変更対象を教えて。
```

**伝えたい内容を変えながら、残したい書式は保つ。** 指定した範囲のフォントや文字サイズ、字間だけを調整する使い方もできます。

### 整列や複製を任せて、レイアウトの検討を進める

同じ大きさの長方形を並べる。パーツを複製する。前後関係を整える。細かな配置操作を言葉で頼めるので、仕上がりを見ながら次の指示を出せます。

```text
この同じ大きさの長方形4つを、両端の位置はそのままで横に均等に並べたい。変更する前に配置案を教えて。
```

図形の移動・拡縮・回転に加え、グループ化や別レイヤーへの移動にも対応しています。グループはまとめて移動できますが、グループの拡縮・回転は対象外です。

### 差し替え画像が届いたら、配置を保って入れ替える

同じ画素サイズで用意した新しい画像へ、リンクを差し替えられます。大きさや位置だけでなく、レイヤーや重なり順も確認します。

```text
選択したリンク画像を、この新しいJPEGに差し替えて。元画像と同じ画素サイズか確認して、大きさと位置はそのままに。
```

新しい画像のリンク配置にも対応しています。**写真の更新と、レイアウトの調整を分けて進められます。**

### 飾りやパーツも、あとから編集できる形でつくる

丸、多角形、スター、直線、ベジェ曲線。AI に依頼してつくった図形は、Illustrator のパスとして編集できます。ポイント文字やスウォッチの作成、RGB文書でのグラデーションの作成も可能です。

```text
開いているドキュメントに、飾り用の丸とスターをつくりたい。配置先と大きさを確認してから進めて。
```

*上記は依頼文の例です。AI が対象データを調べ、対応する文字・図形・画像かを確認してから進めます。対応外の対象は書き込み前に拒否します。*

## もっと活用するなら

**ひとつの修正から、まとめての修正へ。** 複数の一行テキストの差し替えや、別々の対象への文字置換・文字サイズや塗りの変更・図形の移動・パスの外観変更を、一度の依頼にまとめられます。先に全対象を確認し、対応できないものがあれば書き込み前に知らせます。

**「変えること」と「保つこと」を一緒に伝える。** 「文字だけ替えて、サイズと色はそのまま」「画像を替えて、位置と大きさはそのまま」のように頼むと、制作意図を共有しやすくなります。

**確認作業にも使う。** 使用フォントや色、リンク画像の状態、実効解像度、印刷前に気になる項目を調べられます。調べ切れていない項目を、問題なしとは扱いません。

## 元のファイルを残して、差し替え版をつくる

日付違い・価格違い・写真違いの版を、元のファイルを上書きせずに一つずつつくれます。専用の一括ツールはなく、既存のツールを次の順に組み合わせます。

1. 元のファイルを開く。すでに開いている場合は開き直さず、その状態を確認します。
2. 差し替える文字・写真と、維持する書式・配置を伝える。
3. 変更計画を確認し、対応する範囲だけ適用する。複数の変更を続ける場合は、バックアップを確認した連続編集の条件に従います（実質1,000オブジェクトまで）。
4. 変更後の文字・位置・画像を読み直し、Illustratorの画面でも確認する。
5. まだ存在しない新しい名前で保存する。元のファイルが変わっていないことも確認します。
6. 次の版へ進む前に書類を閉じ、元ファイルを開き直す。

プレビュー機能は未保存状態の書類と指定範囲に限定されます。撮影結果を画像比較機能へそのまま渡すことはできません。詳しい条件は[ツール一覧と制限](tools.md)を確認してください。

版の名前（保存先のパス）は依頼のたびに指定します。命名規則を自動で当てはめる機能はありません。

```text
この元ファイルから日付違いの版をつくりたい。「9/20」を「9/27」に替えて、
~/Desktop/banner_0927.ai に別名保存して。元ファイルは変えずに、対象と保存先を確認してから進めて。
```

**対応範囲の制限**

- 差し替えられる文字は、レイヤー直下の一行のポイント文字だけです。グループ内・エリア内文字・複数行の文字は対象外です。
- 差し替えられる画像は、リンク画像を同じ画素寸法の TIFF／JPEG／PNG へ替える場合だけです。埋め込み画像や画素寸法の違う画像への差し替えは対象外です。
- 保存した手順（レシピ）に入るのは文字の差し替え、文字サイズ・塗り、移動、パスの外観だけです。画像の差し替えと別名保存はレシピに入らないため、別の呼び出しになります。
- アートボードの複製・サイズ変更、サイズ違いの版は対象外です。

## コピーして使える依頼例

**複数の見出しをまとめて修正する**

```text
選択した一行テキストの見出しを、次の対応表でまとめて差し替えたい。
旧：「新商品」→ 新：「新発売」
旧：「おすすめ」→ 新：「今月のおすすめ」
それぞれの文字サイズと色は維持して。
対象と変更内容を一覧にして、確認してから実行して。
```

**必要な言葉だけを強調する**

```text
選択した一行テキストの「期間限定」だけ、文字サイズを大きくしたい。
それ以外の文字と書式を保てるか確認して、変更案を教えて。
```

**印刷前にデータを調べる**

```text
Illustrator Studio MCPで、このドキュメントの印刷前検査をして。
画像の解像度、リンク、フォント、細い線、透明やオーバープリントを確認し、
気になる項目と確認できなかった項目を分けて教えて。データは変更しないで。
```

これらは使い方の例であり、特定の制作物での実行結果ではありません。文字は対応する一行のポイント文字、整列は対応する図形が対象です。対象と上限は [ツールと対応範囲](tools.md) を参照してください。
